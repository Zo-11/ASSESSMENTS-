# AltSchool Assessment Parts A and B

This repository contains the Chatter first assignment, the accessible HTML-only AltSchool sign-in form, and solutions to JavaScript Problems 1–5.

## Part A
- `index.html` is the first assignment (Chatter landing page).
- `form.html` is the AltSchool sign-in form. The global navigation at the top of both pages connects them.
- `styles.css` styles the Chatter page. The form itself contains no CSS.

## Part B
- `problems-1-5.js` contains the JavaScript solutions.
